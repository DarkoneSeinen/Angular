# Angular Main - Learning Portfolio

Welcome to my main folder of projects and exercises with **Angular**! Here you'll find everything I've learned and practiced about one of the most modern, efficient, and powerful frontend frameworks in the web ecosystem.

---

## 🚀 What will you find here?

- **Angular CLI Setup and Usage**  
  From installation to project creation and management, I mastered the Angular CLI to speed up development.

- **Components, Directives, and Services**  
  I dove deep into Angular's architecture, building reusable components, custom directives, and services for business logic and data access.

- **Forms and Validation**  
  I implemented both reactive and template-driven forms, applying basic and advanced validations.

- **API Consumption and HTTP Access**  
  I learned to connect Angular apps with external APIs using the HttpClient module, handling requests, responses, and errors.

- **Authentication and Security**  
  I implemented user authentication and route protection, integrating authentication services like Firebase Auth.

- **Optimization and Modularization**  
  I improved app performance by splitting code into modules and applying lazy loading.

- **Deployment and Firebase**  
  I learned to deploy Angular apps on Firebase Hosting and use Firebase as a backend (Firestore, Auth, Storage).

- **TypeScript**  
  All development was done using TypeScript, Angular's main language, taking advantage of its benefits over JavaScript.

- **Bonus: HTML, CSS, and JavaScript**  
  Includes resources and exercises to reinforce web development fundamentals.

---

## 📂 Repository Structure

- **Angular Projects**: Exercises, mini-apps, and complete projects (calculators, online stores, client management, etc.).
- **Firebase Integration**: Examples of authentication, real-time database, and deployment.
- **Additional Resources**: Notes, examples, and utilities for HTML, CSS, and JavaScript.
